# Política de seguridad

Automatizia agradece la divulgación responsable de vulnerabilidades en este repositorio.

## Reporte privado

No publiques vulnerabilidades explotables, credenciales, datos personales ni detalles que permitan comprometer sistemas en issues o pull requests. Usa la función **Report a vulnerability** de GitHub Security Advisories del repositorio. Si no está disponible, contacta a los mantenedores mediante el canal de seguridad publicado en el perfil de la organización Automatizia en GitHub. Incluye versión o commit, impacto, pasos mínimos para reproducir y mitigaciones conocidas. No adjuntes datos de terceros.

## Qué esperar

Los mantenedores confirmarán recepción en un plazo objetivo de cinco días hábiles y coordinarán una evaluación y divulgación pública después de disponer de una corrección o mitigación. Este plazo es un objetivo, no una garantía. Se puede acordar un calendario coordinado con quien reporta. Se agradecerá la colaboración de buena fe y se evitará divulgar identidades sin consentimiento.

## Alcance

Esta política cubre código, scripts, instrucciones y configuración mantenidos en este repositorio. La autorización para probar un skill no implica autorización para escanear sistemas externos: las pruebas deben realizarse en entornos propios o con permiso escrito del propietario.
